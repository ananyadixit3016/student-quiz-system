# Student Quiz System

## About the Project
The Student Quiz System is a beginner-friendly Python project designed to conduct multiple-choice quizzes. It was created to practise Python programming concepts through a simple quiz application.

## Features
- Multiple-choice questions (MCQs)
- Randomized question selection or ordering
- Answer checking
- Automatic score calculation

## Technologies Used
- Python
- Python's built-in `random` module

## How to Run
1. Download or clone this repository.
2. Make sure Python is installed on your computer.
3. Open a terminal in the project folder.
4. Run the following command:

   `python miniproject1.py`

## Learning Objectives
This project helped me practise Python fundamentals, including lists, loops, conditional statements, and randomization.
